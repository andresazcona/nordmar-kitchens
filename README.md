# Nordmar Atelier

Landing page for a fictional bespoke-kitchen brand. React + plain CSS, no animation libraries, no canvas/WebGL.

- Scroll-driven hero: the empty room fills with the kitchen as you scroll.
- Live material configurator with circular wipe transitions.
- Process cards with 3D tilt, filterable portfolio with curtain reveals and parallax.
- Popups (native `<dialog>`) for projects, process steps and a demo contact form (sends nothing).
- Images generated with Gemini.

```bash
npm install
npm run dev
```
